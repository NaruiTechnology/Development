# Fresh CAD workspace

Reserved for a new KiCad project after converter, carrier/interface and analog
requirements are selected. No old schematic, board outline, copper, libraries
or component population is used as the starting design.

Planned schematic blocks: detector protection/conditioning, ADC driver/reference,
ADC/digital interface, XY DACs/output drivers, clocks/control, supplies and
connectors/test access. Part numbers, footprints, rails, net voltages, connector
pin assignments and layout constraints remain to be designed.

No schematic or PCB has been created yet. KiCad CLI is not currently available
on PATH in this environment; use a supported toolchain and record its version
when creating and validating the native CAD source.
