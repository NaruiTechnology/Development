# Milling LiveView contrast

The ROIContrast **View** selector provides three display modes. It does not change beam parameters, detector data or the lower full-image contrast control.

- **Enhanced Auto** uses exact raw-sample 0.5th/99.5th percentiles, excluding unacquired pixels. The histogram outline is still downsampled for drawing, but that downsampling does not affect Auto levels. Level changes settle over 180 ms. Its blue third handle sets the minimum automatic window width (default 12% of the displayed range; adjustable from 2% to 50%). Widen it to reduce noise amplification and keep the black and white levels farther apart. The ordinary black and white handles remain available for manual levels.
- **Change** compares current preview-pixel averages with the preceding completed reference. Zero change is midgray; positive change is brighter and negative change darker. The wedge axis is signed ADC change. A preview pixel is compared only after the same number of exposure samples has contributed as in the reference. Since several beam spots can map to one preview pixel, this is not individual-spot history. The first compatible pass establishes the reference. Manual wedge levels and Auto are stored separately from intensity contrast.
- **Normalize range** adds a two-handle 0–16383 ADC slider above the canvas. **Around mean** initializes the interval around the current mean ± standard deviation, with a minimum width based on Min window. **Brightness** lifts selected values using a monotonic curve so their differences remain visible. Values outside the selected range retain the ordinary intensity mapping. Turning off **Brighten range** bypasses normalization. An empty selected interval produces no invented samples or contrast changes. **Reset** restores the full interval, 75% brightness strength, an 8-code minimum window and Auto levels.

One completed pass/step reference is retained independently of the active frame and saved in local IndexedDB for reuse after reload. Compatibility includes the pattern lattice, world mapping/calibration, equipment, ADC configuration and production/simulation source. Changing these starts a new reference. Partial/stopped passes do not replace a successfully completed reference. If browser storage is unavailable, the reference remains in session memory and the control reports that state.

Production LiveView uses the returned ADC samples. Simulation uses the returned loopback samples. Identical loopback coordinates should produce zero temporal change; controlled synthetic changes were used to validate the difference renderer.
